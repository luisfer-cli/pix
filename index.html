Pixel art reproducible · Rust · .pix DSL

Dibuja sprites como código. Exporta magia pixel-perfect.

pix convierte una DSL mínima en PNGs nítidos, GIFs animados y spritesheets con metadata. Sin antialiasing, sin sorpresas: arte determinista listo para juegos, docs y prototipos.

Código que dibuja

Una DSL pequeña, expresiva y fácil de versionar

Los sprites viven en archivos .pix, así que puedes revisarlos en pull requests, formatearlos, validarlos y regenerarlos en CI.

canvas 16 16
background transparent
strict_palette true

palette {
    O #181425
    G #3fa34d
    L #7bd88f
}

frame idle-1 {
    group slime at 3 5 {
        rect 0 1 10 5 G
        pixel 2 2 O
        pixel 7 2 O
        circle 5 3 2 L
    }
}

Instalación

Empieza en segundos

cargo install --path . pix check examples/slime_anim.pix pix render examples/slime.pix -o output/slime.png pix sheet examples/slime_anim.pix -a idle -o sheet.png --json sheet.json
