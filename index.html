LEVEL 02

Una DSL pequeña para sprites legibles

Los assets se revisan como texto, usan coordenadas enteras y se renderizan siempre igual. Ideal para repos, CI y documentación visual.

canvas 32 32
background transparent
strict_palette true

palette {
    O #111827
    C #06b6d4
    H #cffafe
}

frame pulse-1 {
    group crystal at 10 8 {
        rect 3 4 12 10 O
        circle 9 7 3 C
        pixel 8 6 H
    }
}

animation pulse fps 5 {
    pulse-1
}
