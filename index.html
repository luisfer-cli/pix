PIXEL ART LEGIBLE

El dibujo también es código.

Guarda tus sprites en Git, revisa cambios línea a línea y regenera cada asset cuando quieras.

Abrir ejemplo completo →
crystal_golem.pix
canvas 32 32
background transparent
strict_palette true

palette {
    O #111827
    C #06b6d4
    H #cffafe
}

frame pulse-1 {
    group crystal at 10 8 {
        rect 3 4 12 10 O
        circle 9 7 3 C
        pixel 8 6 H
    }
}
TERMINAL

$ cargo install --git https://github.com/luisfer-cli/pix

$ pix check examples/neon_dragon.pix

$ pix render examples/neon_dragon.pix -o dragon.png --scale 8

$ pix gif examples/crystal_golem.pix -a pulse -o golem.gif --scale 6
